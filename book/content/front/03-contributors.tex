\section{关于作者}
\textbf{Dan Olson} 是一位资深的 C++ 开发者，在电子游戏行业拥有 20 多年经验。他是一位专注的编程语言爱好者，在 Rust 1.\allowbreak{}0 发布之后，便开始把项目从 C、Python 和 C\# 迁移到 Rust，被其安全性与性能所打动。如今，Dan 帮助开发者发掘 Rust 的潜力，以提升软件质量与可维护性。
\section{关于审稿人}
\textbf{内伊茨·加洛夫（Nejc Galof）} 是一位来自斯洛文尼亚的资深软件开发者，在软件工程领域拥有约 10 年经验，专精于计算机视觉与信号处理。他就职于 SICK，负责为工业与企业级应用开发高性能软件解决方案。尽管他拥有深厚的 C++ 背景，如今却主要用 Rust 开发，借助它构建更安全、更快速、更易维护的软件。Nejc 乐于探索前沿的编程语言、工具与技术，为复杂的技术挑战提供实用而创新的解决方案。
