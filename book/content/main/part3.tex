在本书的第三部分，我们将考察一些更高级的主题，例如优化、多线程以及宏开发。我们会探讨这些主题在哪些地方与 C++ 有重叠，又在哪些地方 Rust 给出了完全不同的东西。读完这一部分，你将对用 Rust 工作充满信心，我们还会探讨你 Rust 之旅中几个可能的后续方向。
本书这一部分包含以下章节：
\begin{itemize}
  \item \emph{第 10 章}，\emph{Rust 中的优化}
  \item \emph{第 11 章}，\emph{Rust 中的多线程}
  \item \emph{第 12 章}，\emph{用宏进行元编程}
  \item \emph{第 13 章}，\emph{继续深入 Rust}
\end{itemize}
