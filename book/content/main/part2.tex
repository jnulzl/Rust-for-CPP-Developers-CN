在本书的第二部分，我们将探讨若干与 Rust 标准库相关的主题。我们会学习 Rust 提供的容器、I/\allowbreak{}O、错误处理和迭代器类型，并大量练习使用它们。在此过程中，我们还会了解标准库所用的约定和词汇，以及每个主题如何与 Rust 的安全模型相互作用。学完这一部分，你将能自如地编写 Rust 代码，并对 Rust 标准库以及 crate 生态的部分内容有出色的理解。
本书的这一部分包含以下章节：
\begin{itemize}
  \item \emph{第 5 章}，\emph{数据结构}
  \item \emph{第 6 章}，\emph{读写文件}
  \item \emph{第 7 章}，\emph{理解迭代器}
  \item \emph{第 8 章}，\emph{面向对象编程}
  \item \emph{第 9 章}，\emph{在 Rust 中使用 C++}
\end{itemize}
