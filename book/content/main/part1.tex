在本书的第一个部分中，我们将探索 Rust 的基础知识，包括这门语言及其工具链的技术优势。只要可能，你都会在与之等价的 C++ 代码语境中看到 Rust 语法。读完这部分后，你将能够读懂大部分 Rust 代码，并理解 Rust 在何处、为何做出与 C++ 不同的取舍。你将能够在 Rust 中创建一个基本项目，并对支撑 Rust 生态的工具链有充分的理解。
本书的这一部分包含以下章节：
\begin{itemize}
  \item \emph{第 1 章}，\emph{为什么选择 Rust？}
  \item \emph{第 2 章}，\emph{使用 Rust 语法}
  \item \emph{第 3 章}，\emph{Rust 的安全模型}
  \item \emph{第 4 章}，\emph{用 Cargo 管理 Rust 项目}
